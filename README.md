# PHASE 1:

phase 1 has to be just html and css (no frameworks or javascript) 

each of us makes an html page and an associated css file for the page.

All pages also import `main.css` which contains the color palette

NEVER hardcode colors in your CSS/HTML, use the variables from the color pallete, that way changing the colors later will need just 2 clicks.
